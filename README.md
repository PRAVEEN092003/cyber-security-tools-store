Cyber Security Tools Store

A full-stack web-based Cyber Security Tools Store built using Python Flask, SQLite, HTML, CSS, Bootstrap, and JavaScript.

 🚀 Features

👤 Customer
- Customer registration and login
- Browse cybersecurity tools
- Search and filter products
- View product details
- Add products to cart
- Update cart quantity
- Remove products from cart
- Checkout and place orders
- View order history
- View order details

🛡️ Admin
- Secure admin login
- Admin dashboard
- Product management
- Category management
- Customer management
- Order management
- Update order status
- Revenue overview
- Recent orders

🔒 Security
- Password hashing
- Session-based authentication
- Role-based access control
- CSRF protection
- Parameterized SQL queries
- Secure file upload validation
- Input validation
- Secure session cookies
- Security headers
- XSS-safe content rendering

 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Werkzeug
- Flask-WTF
- Python-dotenv
- Git & GitHub

 🛍️ Product Categories

- Network Security
- Vulnerability Assessment
- Password Security
- Encryption
- Security Monitoring
- System Protection

🔄 Application Workflow

 Customer

Register/Login → Browse Products → Product Details → Add to Cart → Checkout → Place Order → View Orders

 Admin

Admin Login → Dashboard → Manage Products → Manage Categories → Manage Customers → Manage Orders
